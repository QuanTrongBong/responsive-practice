# Responsive Web Practice

Một repository chứa bốn bài thực hành:

1. `responsive-navbar/` — menu mobile mở/đóng bằng nút hamburger.
2. `landing-page/` — landing page có header, hero, dịch vụ, testimonials và footer.
3. `rwd-layout/` — layout responsive bằng CSS Grid.
4. `responsive-gallery/` — gallery theo breakpoint: 4 cột, 2 cột dưới 700px, 1 cột dưới 500px.

Mở `index.html` ở thư mục gốc để chọn bài. Gallery cần Internet để tải ảnh.
